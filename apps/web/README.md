# InfinityHub Web Application (`apps/web`)

Modern, multi-tenant Business SaaS Web Application built with React 19, TypeScript, Vite, Tailwind CSS, and Lucide React.

## Full Documentation
For complete architectural specifications, zero-trust security boundaries, complete sitemap, feature walkthroughs, and test credentials, please see:
👉 **[`docs/WEB_PROJECT_DOCUMENTATION.md`](../../docs/WEB_PROJECT_DOCUMENTATION.md)**

## Quick Start
From the project root:
```bash
# Start Vite development server
npm run dev:web

# Build for production
npm run build:web

# Preview production build
npm run preview:web
```
Server runs at `http://localhost:3000` (or local network IP).
